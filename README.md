# GARCIANO – Smart Tourism Mobile Application

## Project Overview
GARCIANO is a smart tourism Android application designed to promote local tourism, attractions, food destinations, events, and local spots in Padre Garcia, Batangas.

## Technologies Used
- **Programming Language:** Kotlin
- **Framework:** Jetpack Compose
- **UI Design:** Material 3
- **IDE:** Android Studio
- **Authentication:** Firebase Authentication
- **Image Loading:** Coil

## Main Features
- User Registration
- User Login
- Dashboard
- Attractions
- Food and Dining
- Local Events
- Local Spots
- Search Functionality

## Project Structure
The application uses a modular package structure to organize authentication, dashboard, and tourism-related screens.
